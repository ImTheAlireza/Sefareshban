# سفارش‌بان (Sefareshban)

افزونه وردپرس برای مدیریت مدرن سفارشات ووکامرس.

## ویژگی‌ها

- صفحه اختصاصی مدیریت سفارش‌ها با رابط کاربری فارسی و راست‌به‌چپ
- جایگزینی خودکار صفحه پیش‌فرض سفارشات ووکامرس (سازگار با HPOS و حالت Legacy)
- کارت‌های KPI (سفارش‌های امروز، فروش امروز، سفارش‌های در انتظار، میانگین ارزش سفارش)
- نمودارهای روند ۷ روزه و ۳۰ روزه
- فیلتر وضعیت، جست‌وجو، مرتب‌سازی و صفحه‌بندی
- مشاهده جزئیات سفارش در پنل کشویی (Drawer)
- تغییر وضعیت سفارش، ثبت یادداشت داخلی، خروجی CSV
- عملیات گروهی (تغییر وضعیت، انتقال به زباله)
- حالت روشن/تاریک و چگالی جدول

## نصب

1. پوشه `sefareshban` را در مسیر `wp-content/plugins/` قرار دهید.
2. از پیشخوان وردپرس، افزونه **سفارش‌بان** را فعال کنید.
3. از منوی **ووکامرس > سفارش‌ها (سفارش‌بان)** وارد صفحه مدیریت شوید.

## پیش‌نیازها

- وردپرس 6.0+
- PHP 7.4+
- ووکامرس 7.0+

## توسعه

رابط کاربری بر اساس طرح ارائه‌شده پیاده‌سازی شده و داده‌ها به‌صورت زنده از طریق AJAX از ووکامرس خوانده می‌شوند.
